# Climate-Housing Exposure Index Dashboard — GitHub Pages Release

This folder is ready for static GitHub Pages publication. Upload **`index.html`** and **`.nojekyll`** to the root of a public GitHub repository, or upload the entire folder contents.

## Publish

1. Create or open the intended GitHub repository.
2. Upload the contents of this folder to the repository's default branch.
3. Open the repository's **Settings → Pages** page.
4. Under **Build and deployment**, select **Deploy from a branch**, then select the default branch and **/(root)**.
5. Save and wait for GitHub to display the public HTTPS URL.

The HTML is self-contained for the analytical dashboard. Internet access is still needed for the CARTO/OpenStreetMap basemap tiles and the external MathJax script.
